# TransitPay-Prototype
A prototype Android transit payment system built with ASP.NET Core, PostgreSQL, and React.

A portfolio project demonstrating a modern transit fare payment system.

## Technologies

- Jetpack Compose
- ASP.NET Core Web API
- PostgreSQL
- React
- JWT Authentication
- QR Code Ticketing

## Project Structure

/backend - REST API

/passenger-app - Android Passenger App

/driver-app - Android Driver App

/admin-dashboard - React Dashboard

/database - SQL Scripts

/docs - Documentation
